## Completeness summary

| Category | Status |
| --- | --- |
| Head coach, OC, DC (or co-DC) for all 16 | **Complete** (Mississippi State has no separate OC; HC Jeff Lebby oversees offense) |
| Special teams coordinator | **Complete** for all 16 |
| QB / RB / WR position coaches | **Complete** for nearly all 16; Florida and LSU list split WR rooms (outside / inside); Georgia OC also coaches QBs |
| Offensive scheme labels | **Strong** for Veer & Shoot / tempo-spread cohort and several others; some programs lack a single official label |
| Defensive scheme labels | **Mixed** — several base fronts documented (e.g., Georgia 3–4, Alabama 4–2–5, Tennessee Knowles 4–2–5); others **Not listed** when only multiple/flexible language appears without a published base |

**Major gaps:** (1) Arkansas, Auburn, Florida, Kentucky, Missouri, Oklahoma (base front), South Carolina, Texas A&M, and Vanderbilt lack a single, official public “base defense” tag in sources consulted — reported as **Not listed** or carefully attributed multiples. (2) Florida’s Brad White / Buster Faulkner scheme labels are weakly standardized in public sources. (3) Mississippi State Wikipedia roster briefly lagged Clarion Ledger / 247Sports on co-DC title (Matt Brock) after Matt Barnes’s departure — this report follows Clarion Ledger / 247Sports / FBS coaches list.

## Conference notes (2026)

1. **Veer & Shoot prevalence:** Sports Illustrated (2026) identified the Veer & Shoot (or close tempo/wide-split relatives) as the primary scheme for roughly seven SEC offenses, citing practitioners tied to Heupel, Lebby, Briles, Kiffin, Golesh, Cramsey, and Baker among others. Exact membership can blur when coaches reject the media label (e.g., Golesh).
2. **New head coaches (2026):** Ryan Silverfield (Arkansas), Alex Golesh (Auburn), Jon Sumrall (Florida), Will Stein (Kentucky), Lane Kiffin (LSU). Pete Golding continues as Ole Miss head coach after succeeding Kiffin.
3. **Title ambiguity:** Several programs use co-coordinator titles; Oklahoma’s Bates is officially Co-DC while Venables remains deeply involved defensively; Mississippi State lists no separate OC.
